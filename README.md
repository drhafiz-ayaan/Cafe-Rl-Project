# Cafe RL Project

This project trains a reinforcement learning (RL) agent to optimize cafe service
(human vs. robot) based on given rules and customer order data.

---

## 📂 Project Structure
- `cafe_rl.py` → main script
- `Rules.docx` → rules provided by client
- `data/` → order CSV files
- `reward_curve.png` → training reward curve
- `requirements.txt` → list of dependencies
